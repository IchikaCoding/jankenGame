# Janken Game

## プロジェクト概要
- ブラウザ上で遊べるじゃんけんゲームのプロトタイプです。
- HTML (`index.html`)、CSS (`styles.css`)、JavaScript (`script.js`) の3ファイルで構成され、外部ライブラリは使用していません。
- ラウンドごとの勝敗ロジックとUIの骨組みは実装済みですが、ボタン操作によるラウンド進行や最終勝者の確定処理は開発途中です。

## 画面構成（`index.html`）
- ルール説明をまとめた `<details>` セクションを用意しており、初めてでも遊び方を確認できます。
- プレイヤーとコンピューターのスコアを表示するカウンター。
- 「Rock」「Paper」「Scissors」の3ボタンでプレイヤーの手を選択します。
- ラウンド結果メッセージ、最終勝者メッセージ、再戦ボタン（初期状態は非表示）の表示領域。

## ゲームルール
- プレイヤーは各ラウンドで「Rock」「Paper」「Scissors」から1つ選び、コンピューターと勝負します。
- 勝敗は「Rock > Scissors」「Scissors > Paper」「Paper > Rock」で決まります。
- ルール表示では「先に3ポイント取った側が勝利」と定義されていますが、JavaScript側ではまだこの勝敗判定処理が実装されていません。

## 実装のポイント（`script.js`）
- `getRandomComputerResult()`：コンピューターの手を等確率で決定します。
- `hasPlayerWonTheRound(player, computer)`：プレイヤー勝利かどうかを判定します。
- `getRoundResults(userOption)`：ラウンド結果メッセージを生成し、勝者のスコアを更新します。
- `showResults(userOption)`：最新のスコアとメッセージをDOMに反映します。
- スコア表示や結果メッセージのDOM要素は取得済みですが、ボタンのクリックイベント、3ポイント到達時の処理、リセット処理は未実装です。
- 初期表示のために `showResults("Rock")` を1度呼び出し、画面に仮の結果メッセージを表示しています（ユーザー入力は未連動）。

## 現状の課題
1. 各ボタンに `showResults` を結び付けておらず、プレイヤーの選択がロジックに届きません。
2. 3ポイント先取での勝利判定と `winner-msg`／`reset-game-btn` の表示切り替えが未完了です。
3. スコアを初期化するリセット処理がなく、再戦時にスコアがリセットされません。
4. デバッグ用の `console.log` が残っているため、リリース前には整理が必要です。

## 動作方法
1. プロジェクトルートで `index.html` をブラウザで開きます。
2. 画面と初期メッセージは表示されますが、完全にプレイするためにはイベント処理などの追加実装が必要です。

## ディレクトリ構成
```
jankenGame/
├─ index.html     # 画面の骨組みとルール説明
├─ styles.css     # 配色・レイアウト定義
└─ script.js      # じゃんけんロジックとDOM操作
```
